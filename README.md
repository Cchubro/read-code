# read-code

Reading source code is a headache. I do it anyway.

I read one repo at a time and find the one core decision it's built on — then explain it in plain language, with the file and line to prove it. No BS walk-throughs. One repo, one decision, one stealable pattern.

Follow along on X: https://x.com/Lucas_xhub

## Tools I built

- [thread-splitter](https://github.com/Cchubro/thread-splitter) — split long text into a numbered thread that fits X's 280-character limit.
- [readme-to-thread](https://github.com/Cchubro/readme-to-thread) — turn a repo README into a launch-thread draft.
- [topic-agent-templates](https://github.com/Cchubro/topic-agent-templates) — 7 topic templates × 9 fixed columns, one a day, ready to use.
- [mouse-trajectory-test](https://github.com/Cchubro/mouse-trajectory-test) — a test page that records browser mouse movements and bot-detection signals.

That's it. Read code, steal the decision, build something.
